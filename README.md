# Let's Do

**Plan it. Do it. Feel good.**

Let's Do is a personal daily planning and progress-tracking application designed to help users organize their time, build consistent routines and celebrate achievements.

## Project Status

In development.

## Planned Tech Stack

- Frontend: React, TypeScript, Tailwind CSS
- Backend: Python, FastAPI
- Database: PostgreSQL
- Authentication: Supabase Auth
- Platform: Responsive Progressive Web App (PWA)

## Development Approach

Built using an AI-assisted development workflow with human-led requirements, architecture decisions, code reviews and testing.
